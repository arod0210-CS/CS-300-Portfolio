## Project Overview

In CS 300, I worked on developing a course advising application for ABC University (ABCU). The main goal was to create a program that could load course information, display a list of courses in alphanumeric order, and show the course title and prerequisites when a user searches for a specific course.

Throughout the course, I explored different data structures, including vectors, hash tables, and binary search trees. These projects helped me understand how choosing the right data structure can affect a program's performance, memory usage, and overall design.

## Portfolio Artifacts

**Project One — Data Structure Analysis**

For Project One, I developed pseudocode and compared the runtime and memory requirements of vectors, hash tables, and binary search trees. I evaluated their advantages and disadvantages and recommended a vector for the smaller ABCU course catalog because of its simplicity and ease of maintenance.

**Project Two — C++ Course Planner**

For Project Two, I developed a C++ program that allows academic advisors to load course data, print an alphanumerically sorted course list, and look up individual courses and their prerequisites. The program uses a menu system so users can select the information they need.

## Reflection

### What was the problem you were solving in the projects for this course?

The problem I was trying to solve was helping academic advisors access course information more efficiently. Instead of manually looking through course records, the program allows users to load a file, view a sorted course list, and find the prerequisites for individual courses. Project One focused on planning and evaluating different ways to organize the information, while Project Two focused on putting that design into a working C++ program.

### How did you approach the problem? Consider why data structures are important to understand.

I started by breaking the problem into smaller tasks, such as loading the data, storing course information, sorting the courses, and searching for specific courses. I compared vectors, hash tables, and binary search trees to understand how each structure handles these tasks.

One important thing I learned is that data structures directly affect how efficiently a program works. Some structures are better for searching, while others make sorting or storing information easier. Understanding these differences helped me make better decisions instead of just choosing the first approach that worked.

### How did you overcome any roadblocks you encountered while going through the activities or project?

One challenge I encountered was getting the C++ program to load the course data file correctly in Eclipse. At first, the program could not locate the CSV file, so I had to troubleshoot the file location and make sure the application was using the correct path.

I also had to work through understanding the differences between the data structures and how their runtime performance changes depending on the amount of data. Breaking the problem into smaller steps, testing the program, and reviewing the results helped me work through these challenges.

### How has your work on this project expanded your approach to designing software and developing programs?

This project helped me understand why planning is an important part of software development. Before this course, I focused more on getting my code to work. Now I think more about how the program should be organized, what data structures make the most sense, and how the design could affect performance as the application grows.

Working with pseudocode before implementation also helped me see how planning can make the coding process easier. I learned to evaluate different solutions before deciding which one to use.

### How has your work on this project evolved the way you write programs that are maintainable, readable, and adaptable?

I have become more aware of how important it is to write code that is easy to understand and maintain. Throughout these projects, I practiced separating different tasks into functions, using descriptive names, and keeping the program organized.

I also learned that choosing a simple design can sometimes be better than using a more complicated structure, especially when working with a smaller amount of data. Moving forward, I want to continue writing programs that are easier to troubleshoot, update, and expand without having to rewrite everything.

## Conclusion

CS 300 helped me improve my understanding of data structures, algorithms, and software design. I gained more experience with C++, pseudocode, runtime analysis, and problem-solving. These are skills I plan to continue developing as I finish my Computer Science degree and work toward becoming a software developer.
